## 三、本阶段任务（T8–T12）

**T8 金标准评测模块（本阶段核心，立即执行）**
落实方案 2.3 评测方法：以真实病历为金标准，将原始素材输入系统生成草稿，与医生真实书写版本**逐字段比对**，产出覆盖率/相似度/可用率，作为验收与迭代的客观依据。
- 金标准：闫秋荣 2023-11-01 住院（胆总管结石伴急性胆管炎、胆囊结石伴急性胆囊炎）入院记录，字段值从院内 XML 病案逐字提取；该次住院共 21 份文书（入院记录、首次病程、查房×5、用药×3、术前小结、手术记录、知情文件×4 等），是院方认可的完整金标准全集。
- 系统新增"金标准评测"视图：选择金标准案例 → 运行六智能体生成 → **AI 草稿 vs 金标准逐字段对照表**（相似度判定：≥0.85 一致 / 0.6–0.85 基本一致 / <0.6 偏差 / 缺失）→ 指标卡（字段覆盖率、平均相似度、可用率）→ 评测报告 MD 导出。
- 相似度算法：字符级 bigram F1（对中文医学表述稳健、无需分词），代码内置可替换。

**T9 ASR 选型测试准备**
- 评测页内置"ASR 选型测试集"面板：门诊 5 组音频（1–5.m4a，对应患者照片 1–5.jpg）登记造册；
- 引擎适配器状态一览（演示/浏览器已可用，讯飞/阿里待 Key）；
- 拿到 Key 后的测试执行清单（字准率/医疗热词/时延/成本四维，对应方案 4.2）。

**T10 第二文书类型：首次病程记录生成**
金标准全集含首次病程（病例特点/诊断依据/鉴别诊断/诊疗计划），鉴别诊断为知识库驱动——作为生成智能体的第二种模板扩展，评测模块同步支持双文书对照。

**T11 出院记录生成**
数据齐备（金标准含出院记录），实现"全程数据汇总→出院记录"的多源汇聚生成路径。

**T12 部署与安全加固**
- 演示数据脱敏开关（一键替换真实姓名为化名，满足对外演示要求，对应问题清单 #6）；
- 启动脚本参数化（端口/脱敏模式）；单文件打包说明。
