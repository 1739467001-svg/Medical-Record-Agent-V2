## 四、字段质量分析

**入院记录（fast 模式代表轮，8 字段全文）：**

| 字段 | 输出 |
|---|---|
| 主诉 | 腹痛1天 |
| 现病史 | 患者于1天前（昨天下午）无明显诱因出现腹痛，伴恶心、呕吐，呕吐2至3次，无心慌。遂至当地镇上诊所肌注药物治疗（具体药物不详），症状稍缓解，至夜间2点多腹痛加重。为求进一步诊治来我院就诊。 |
| 既往史 | 既往体健，否认心脏病史。 |
| 过敏史 | **否认药物过敏史。**（方言"嗯，没有"→规范否认句，3/3 轮命中；DeepSeek 全系此处输出空串） |
| 家族史 | （空串——素材无信息，符合零编造铁律） |
| 婚姻史 | **育有2个男孩。**（"几个孩子，两个男孩"→婚育规范表述） |
| 个人史 | 生于原籍、久居本地；否认疫区疫水接触史，无烟酒嗜好。（规范兜底句，字段规范明文允许） |
| 初步诊断 | 阑尾炎（与门诊诊断原文一致，不改名不新增） |

**方言把握为三家最佳**：过敏史、育 2 子 3/3 轮稳定命中；"要心慌的上的吗？…不心烦"准确转化为"无心慌"（转写纠错段本身把这句修错了，模型结合 ASR 原文自行纠回）。

**轻微瑕疵（1 处，已记录）**：首次病程"诊断依据"写入"右下腹压痛阳性"——素材未明示查体阳性体征（转写仅有医生触诊问痛对话）。属临床常识性推断越界，靠医生分色核对环节拦截，不计硬编造。
